# LiftNode exploded-view masters

Kept outside `docs/`, so MkDocs does not publish them.

`docs/RESEARCH/PhD/LIFTNODE-EXPLODED-{zh,en}.mp4`.

Source and renderer: `LiftNode_ESP32/DOC/media/exploded-view/` and `LiftNode_ESP32/DOC/tools/viewer-capture/`.
