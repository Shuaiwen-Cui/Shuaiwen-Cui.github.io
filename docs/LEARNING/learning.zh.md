# __求索__

> 路漫漫其修远兮，吾将上下而求索。——屈原《离骚》

这里是我的知识体系，分为两个部分。**工程与实践**是形而下之「器」：芯片、信号、网络与系统，让智能落在真实的硬件与环境里；**理论与算法**是形而上之「道」：计算、学习与推理，回答智能何以可能、如何更好。器以载道，道以御器，两者相互印证，也是我做研究的方式。
