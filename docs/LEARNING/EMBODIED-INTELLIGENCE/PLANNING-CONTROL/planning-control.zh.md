# 规划与控制

!!! abstract "这一页解决什么"
    规划回答"走哪条路、按什么轨迹动"，控制回答"执行中出现误差怎么修正"。这是机器人最经典、可解释的部分，也是学习型策略的对照基线。**必修入门**；你的反馈控制与系统辨识背景可以直接迁移。

## 核心知识

**路径与轨迹**：路径是几何上的点序列，轨迹在路径上加了时间（速度、加速度）。规划常先找无碰撞路径，再做时间参数化满足速度和加速度限制。

**搜索式规划**：A* 在离散网格或图上找最短路径，启发函数不高估时保证最优。适合二维导航，维度高时状态空间爆炸。

**采样式规划**：RRT、PRM 在连续空间随机采样并连成树或图，适合机械臂这类高维构型空间；RRT* 渐近最优。结果需要平滑。

**轨迹优化**：把轨迹写成优化变量，最小化代价（时间、能耗、平滑度）并满足约束（碰撞、关节限位）。CHOMP、TrajOpt 是代表；对初值敏感。

**反馈控制**：PID 按误差、误差积分和误差变化率给出控制量，是最常见的基线。轨迹跟踪 = 前馈（按期望轨迹算）+ 反馈（修正偏差）。

**模型预测控制（MPC）**：每个控制周期用模型预测未来一段时间，在线求解带约束的优化，只执行第一步，下周期重算。能显式处理约束，代价是计算量；足式机器人和自动驾驶广泛使用。

**力控与阻抗控制**：接触任务（插孔、擦拭）不能只控位置。阻抗控制让末端表现得像弹簧-阻尼系统，碰到环境时柔顺而不是硬顶。

**全身控制**：人形和足式机器人要同时满足平衡、接触和多个任务目标，常写成带优先级的二次规划。

## 路线之争 · 模型驱动 vs. 学习驱动

模型驱动（规划 + MPC）可解释、有安全约束、数据需求少，但需要准确模型、难以处理复杂接触和感知不确定性；学习驱动（模仿、强化学习）能从数据中学到难以建模的行为，但需要大量数据、失败难解释。趋势是分层：学习决定"做什么"，模型驱动的控制器负责"安全地做"。

## 自测

??? question "A* 的启发函数为什么不能高估？"
    高估会让算法过早放弃真正最优的路径，失去最优性保证；不高估（可采纳）时 A* 保证找到最短路径。

??? question "机械臂规划为什么常用 RRT 而不是 A*？"
    机械臂构型空间维度高（6–7 维），网格化后状态数指数爆炸；采样方法不需要显式离散整个空间。

??? question "MPC 相比 PID 的优势和代价？"
    优势：显式处理约束、利用模型预测未来、多变量协调；代价：需要模型、每周期求解优化，计算量大，实时性要求高。

??? question "为什么接触任务需要阻抗控制？"
    纯位置控制遇到位置误差时会产生很大的接触力，可能损坏工件或机器人；阻抗控制让接触力与偏差成比例，表现柔顺。
